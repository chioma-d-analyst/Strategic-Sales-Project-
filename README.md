# Strategic Sales Dashboard

## Project Overview

This project presents an interactive Strategic Sales Dashboard developed using Microsoft Power BI.

The dashboard provides a clear view of sales performance and key business metrics, helping users understand sales trends, revenue performance, customer activity, and overall business performance.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft excel
  

## Project Work

I developed this Power BI project from scratch. The work included:

- Data preparation and transformation using Power Query
- Data modelling
- Creating DAX calculations and measures
- Designing interactive dashboard pages
- Creating KPI cards and visualizations
- Using slicers and filters for interactive analysis
- Presenting sales information in a clear and meaningful way

## Dashboard Features

- Sales performance analysis
- Revenue and key performance indicators
- Customer analysis
- Sales trends and patterns
- Interactive slicers and filters
- Strategic business visualizations
